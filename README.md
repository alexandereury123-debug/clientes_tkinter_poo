# Tkinter con POO

Implementando arquitectura de separación por capas (un prototipo de la misma).

## Arrancar la aplicación

```
python | python3 -B main.py
```

## Estructra del proyecto

```
proyecto/
│
├── main.py
│
├── models/
│   └── client.py
│
├── repositories/
│   └── client_repository.py
│
├── services/
│   └── client_service.py
│
└── ui/
    └── app_window.py
